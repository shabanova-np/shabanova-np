## Наталья Шабанова | Аналитик данных


Я аналитик данных с 10+ годами опыта в научной деятельности и 1,5 годами опыта в коммерческой IT-разработке. 

Ищу стажировку / Junior-позицию аналитика данных в продуктовой компании (Москва, удалённо или гибрид).


### Мой стек
- Требования: сбор, формализация, согласование
- Моделирование: BPMN 2.0.
- API и интеграции: REST.
- Данные: SQL (SELECT, JOIN, GROUP BY, HAVING, подзапросы, агрегаты) в PostgreSQL; 
- Инструменты: Miro, draw.io, Git.
- Методологии: Agile, Scrum, планирование спринтов.
